# Renk Avcısı

**Yaş:** 6-9 · **Accent:** emerald

Spektral imza sezgisi kazandıran renk bulma oyunu.

## Mekanik

- 8x8 piksel ızgarası (yeşil/mavi/kahve/gri).
- Görev paneli: "Sağlıklı Bitki bul!" → doğru renge tıkla.
- 3 hedef ardışık, her doğru +15 puan.
- İpucu: "Yeşil alanlar bitki örtüsüdür".

## Sahne ekleme

`src/data/scenes.ts` içine yeni sahne ekle ve bu klasörde 8x8 piksel matrisini
üreten bir generator tanımla.
